What changed

This patch fixes a navigation race that could leave a nested route waiting when streaming was interrupted and restarted.

Fixes

  • Preserve pending route segments after an aborted navigation.
  • Avoid rendering stale layout state during a streamed refresh.
  • Improve error recovery when a parallel route is retried.

Upgrade

Update your app to the latest patch release:

npm install next@16.2.1

Full details are available in the upstream release notes.
